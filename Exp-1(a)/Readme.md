How to see output?

Open the browser and enter the following URLs.

URL	                                    Expected output
localhost:3000/         	            Welcome to ExpressJS
localhost:3000/user/Ravi	            User Name: Ravi
localhost:3000/search?keyword=React	    Search: React
localhost:3000/url	                    Generated URL: http://localhost:3000/user/John
